## Сборка
Компиляция и получение dump файла примера на Си выполняется с специального RISCV-совместимого компилятора.

Компиляция:
```
riscv64-unknown-elf-gcc -march=rv32i -mabi=ilp32 {ПУТЬ_К_ИСХОДНОМУ_ФАЛУ} -o {ИМЯ_РЕЗУЛЬТИРУЮЩЕГО_ИСПОЛНЯЕМОГО_ФАЛА}.elf
```
Получение дамп-файла:
```
riscv64-unknown-elf-objdump -D {ПУТЬ_К_ИСПОЛНЯЕМОМУ_ФАЙЛУ} > {ИМЯ_РЕЗУЛЬТИРУЮЩЕГО_ФАЙЛА}.dump
```
